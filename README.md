# Тестовое задание.

## Описание решения

Данное решение включает тестирование API QIWI Кошелька на основе предоставленной документации.

### Что реализовано:

1. **Postman коллекция** (`postman_collection/`)
   - Проверка доступности сервиса (профиль)
   - Проверка баланса (баланс > 0)
   - Создание платежа на 1 рубль
   - Проверка исполнения платежа

2. **Playwright автотесты** (`tests/api.spec.ts`)
   - API тесты на TypeScript
   - Проверка структуры ответов
   - Валидация бизнес-логики (баланс > 0, статус платежа)

### Как запустить:

**Postman:**
1. Импортировать коллекцию из папки `postman_collection`
2. Запустить запросы вручную или через Collection Runner

**Playwright:**
```bash
npm install
npx playwright test
